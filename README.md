# Master Ji Cut Piece Centre — Flutter starter

A cross-platform Android/iOS starter for a wholesale + retail fabric business hub.

## Included
- Responsive Material 3 business dashboard
- Product catalogue with four supplied product photographs
- Add-product form with top/bottom metres, wholesale/retail prices and stock
- Orders workflow placeholder
- Owner/staff permissions overview
- Sales and reports placeholder
- Wholesale + retail business branding

## Run locally
1. Install Flutter SDK and Android Studio / Xcode.
2. From this folder run `flutter create .` (creates platform folders if absent).
3. Run `flutter pub get`.
4. Run `flutter run` on an emulator or connected device.

## Important production work still required
This is a UI starter/demo, not a live commerce backend. Before real customer use, add Firebase or another backend, secure authentication and server-enforced roles, cloud image storage, order/inventory synchronization, payment gateway, shipping integration, privacy policy, terms, and testing. The role switch in this demo is for preview only and is not authentication. Prices and sales figures are sample defaults, not verified business data.

## Product setup
The first sample item is prefilled as Muslin Cotton top 2.25 m + Rayon bottom 2.25 m (4.5 m total). Price and stock are intentionally blank/zero until supplied by the business owner.
